# ARSHAKUHI — Premium Streetwear Store

A responsive, single-file storefront concept for ARSHAKUHI, built with HTML, CSS, and vanilla JavaScript. No build step is required.

## Included in this preview
- Responsive desktop and mobile layout
- Product cards, category filters, and product search
- Demo shopping bag with quantity controls and subtotal
- Animated details and mobile-friendly navigation

## Important before launch
This is a **front-end demo**, not a live ecommerce checkout. It does not take payments, store customer information, create real orders, or send orders to Qikink. Product images and sample prices are placeholders. Replace them with your actual products and confirmed prices before launch.

To accept real orders, connect an ecommerce platform and payment gateway, configure shipping/returns/privacy policies, and set up Qikink using its current official integration instructions. Never put passwords or private API keys in this public repository.

## Free static preview
The site has no build command. For Cloudflare Pages, connect the Git repository `mrrakhi/arshakuhi-store`, choose framework preset **None**, leave the build command blank, and set the build output directory to `/`.
